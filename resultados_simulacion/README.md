# Resultado de la simulación

`ost_simulado.yaml` es un ejemplo generado al pulsar **CALIBRATE** y **SAVE** en `camera_calibration` usando el tablero virtual del paquete. Corresponde a una cámara simulada ideal de 640 × 480 píxeles, no a la cámara integrada ni a la USB. El valor `camera_name: narrow_stereo` es el nombre predeterminado que escribió el calibrador.

No utilices estos parámetros para corregir imágenes de una cámara real. Consulta `GUIA_SIMULACION.md` para repetir la prueba.
